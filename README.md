# 💰 Finance Manager

**Финансовый помощник** — веб-приложение для учёта личных доходов и расходов с возможностью категоризации, отслеживания долгов и анализа бюджета.

---

## 🚀 Возможности

- ✅ Регистрация и авторизация пользователей
- ✅ Добавление доходов и расходов с выбором категории
- ✅ Категоризация транзакций (ручное создание категорий)
- ✅ Просмотр списка всех транзакций с фильтрацией по типу
- ✅ Статистика: общий доход, расход, баланс
- ✅ Цветовая индикация баланса (зелёный/красный)
- ✅ Адаптивный интерфейс на Bootstrap
- ✅ Защита маршрутов (только для авторизованных)

## 🧠 Модели данных

### User (кастомная, наследуется от AbstractUser)
Хранит пользователей системы.

### Category
- `title` — название категории
- `user` — владелец (связь с User)

### Transaction
- `title` — название транзакции
- `amount` — сумма (Decimal)
- `user` — владелец
- `category` — категория (ForeignKey)
- `type_transaction` — доход/расход
- `date` — дата создания (автоматически)
- `description` — описание (опционально)

## 🔧 Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone <url-вашего-репозитория>
cd Django-Finance
```
### 2. Создайте и активируйте виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate # Linux/Mac
venv\Scripts\activate    # Windows
```

### 3. Создайте и активируйте виртуальное окружение
```bash
pip install -r requirements.txt
```

### 4. Создайте и примените миграции
```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Обязательно создайте админа для манипуляций с категориями в админке
```bash
python manage.py runserver
```

### 6. Запустите локальный сервер
```bash
python manage.py runserver
```

Сайт будет доступен по адресу: 
После запуска понадобится создать категории через админку /admin/, например:
- Еда
- Транспорт
- Зарплата
- Развлечения
